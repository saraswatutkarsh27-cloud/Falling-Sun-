========================================
  ABOUT THE PROJECT
========================================

Falling Sun is a premier hackathon website built with React, TypeScript,
Vite, Tailwind CSS, and Framer Motion. It features a modern, animated UI with
three hackathon tracks: Game Development, Web Development, and Robotics.

Key features:
- Animated hero section with GPU-powered mouse parallax
- 12H + 12H 2-day format explained in interactive sections
- Track showcase with horizontal scrolling
- Schedule timeline
- Prizes section
- Team member grid with modal details
- FAQ accordion
- Registration portal with countdown lock
- WhatsApp community integration
- Responsive design (mobile + desktop)
- Smooth page transitions and scroll animations
